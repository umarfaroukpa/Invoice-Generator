# Invoice Generator

A simple PHP invoice generator built to practice backend development with PHP.

This project allows users to create invoices by entering customer details and multiple items. The system calculates totals automatically and displays a clean invoice output.

## Features

- Form handling using POST request
- Input validation
  - Prevents empty fields
  - Prevents negative values
- Multiple invoice items
- Currency formatting
- Simple and clean UI with CSS styling
- Dynamic total calculation
- PDF download support 

## Tech Stack

- PHP
- HTML
- CSS

## Project Goal

I built this project to improve my understanding of PHP form handling, validation, calculations, and backend logic. It also helped me practice working with arrays and handling multiple user inputs.

## How It Works

1. Enter customer details
2. Add one or multiple items
3. Enter quantity and price
4. Submit the form
5. The system calculates the total and generates the invoice

## Installation

1. Clone this repository

```bash
git clone your-repo-link
```

2. Move the project folder to XAMPP `htdocs`

```bash
C:\xampp\htdocs
```

3. Start Apache in XAMPP

4. Open in browser

```bash
http://localhost/your-project-folder
```
